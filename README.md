# CLILLM

A lightweight terminal-based AI assistant built with Go and powered by Ollama.

### Requirements
- Go
- [Ollama](https://ollama.com/)
- A downloaded LLM model (e.g. `llama3.2`)

### Run

```bash
# Start Ollama
ollama serve

# Pull a model
ollama pull llama3.2

# Clone the repository
git clone https://github.com/USERNAME/CLILLM.git
cd CLILLM

# Run
go run .
```
